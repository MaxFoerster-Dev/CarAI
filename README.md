# CarAI

This project features a self-trained AI inside a racing game.

## How to use

### 1. Install Python
First, you need **Python** installed on your system. You can download the latest version from the [Official Python Download Page](https://python.org/downloads).

### 2. Install NumPy
Second, you need to install **NumPy** using the Python package manager **pip**. 

* **On Debian/Ubuntu systems:** If pip is not installed, open your terminal and run:
  ```bash
  sudo apt update && sudo apt install python3-pip
  ```
* **Install the library:** Then, run the following command to install NumPy:
  ```bash
  pip install numpy
  ```

### 3. Run the Game
Make sure you have both `game.py` and the `best_brain.npz` file located in the exact same folder. 

Open your terminal, navigate to that folder, and execute the game using this command:
```bash
python3 game.py
```
